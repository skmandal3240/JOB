# Projects

Every checkpoint from `CURRICULUM.md` gets its own folder here, e.g.:

```
projects/
  phase0-foundations/
  phase1-dsa/
  phase2-data-analysis/
  phase3-classical-ml/
  phase4-deep-learning/
  phase5-indic-finetune/
  phase5-gpu-benchmark/
  phase5-speech-pipeline/
```

Each folder should have its own `README.md` with: the problem, your approach, and results (numbers/screenshots/demo link) — not just a description. This is what `SKILL_TRACKER.md` scores against.
